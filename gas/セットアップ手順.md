# カタモン ランキング — GASのセットアップ手順

この作業は**あなた自身のGoogleアカウントで**行う必要があります。所要15〜20分程度。

**ゲーム専用のGoogleアカウントを新規作成して、そこで作業してください。**
デプロイ先のURLはゲームのソースコードに書き込まれ、公開リポジトリに入ります。つまり誰でもそのURLを叩ける状態になるので、普段使いのアカウントとは分けておくのが安全です。

---

## 1. スプレッドシートを作る

1. 専用アカウントでログインした状態で https://sheets.new を開く
2. 名前を `カタモン ランキング` などに変更する

シートの中身は空のままで構いません。必要なシートと見出し行はスクリプトが自動で作ります。

## 2. スクリプトを貼り付ける

1. そのスプレッドシートで **拡張機能 → Apps Script** を開く
2. 最初から入っている `function myFunction() {}` を**全部消す**
3. `gas/ranking.gs` の中身を全部コピーして貼り付ける
   - GitHubから開けます: https://github.com/futsalife24-bot/katamon/blob/master/gas/ranking.gs
   - 右上の「Raw」を押すと選択しやすくなります
4. プロジェクト名を `カタモン ランキング API` などに変更して保存

**必ずスプレッドシートの「拡張機能」から作ってください。** こうするとスクリプトがそのシートに紐づくので、シートIDをコードに書かずに済みます。単体のApps Scriptプロジェクトとして作ると動きません。

## 3. ウェブアプリとしてデプロイする

1. 右上の **デプロイ → 新しいデプロイ**
2. 歯車マークから **種類の選択 → ウェブアプリ**
3. 設定:

   | 項目 | 値 |
   |---|---|
   | 説明 | `v1` など何でも |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |

4. **デプロイ**を押す
5. 初回は権限の確認が出ます。**詳細 → (プロジェクト名)に移動 → 許可** と進んでください
   - 「このアプリはGoogleで確認されていません」という警告が出ますが、自分で書いたスクリプトなので問題ありません
6. 表示された **ウェブアプリのURL** を控える

URLはこの形です:

```
https://script.google.com/macros/s/AKfycb.....................ここが長い.../exec
```

**この `/exec` で終わるURLを私に教えてください。** ゲーム側に組み込みます。

## 4. 動作確認

控えたURLの末尾に `?action=top` を付けてブラウザで開いてください。

```
https://script.google.com/macros/s/..../exec?action=top
```

こう表示されれば成功です。

```json
{"period":"2026-07","total":0,"top":[],"me":null,"ok":true}
```

エラーが出る場合は、その画面をそのまま見せてください。

## 仕様

- **順位**: 連勝数が主、同数なら与ダメ効率(与ダメ÷発射数)で決める
- **記録の単位**: 端末ごと。自己ベストを更新した時だけ上書きされる
- **集計期間**: 月ごと。毎月1日に自動で新しい期間へ切り替わる(過去の行はシートに残る)
- **表示**: 上位20位 + 自分の順位
- **送信のタイミング**: 連勝が途切れた瞬間。フリーモードは送らない
- **認証**: なし

## 不正対策について

友人内で遊ぶ範囲を想定しているため、**最低限しか入れていません**。

- 連勝200超・効率500超の申告は保存しない
- 1台あたり1日60回までしか受け付けない
- 名前は12文字まで、改行やタブは除去

**全ロジックがブラウザ側にあるので、その気になればスコアは偽装できます。** 本気で守るならサーバ側での再計算が必要ですが、そこまではやらない方針です。

## 後から変更したい時

`ranking.gs` の先頭にある定数を書き換えて、**デプロイ → デプロイを管理 → 鉛筆マーク → バージョン「新バージョン」→ デプロイ** で反映されます。

| 定数 | 意味 |
|---|---|
| `MAX_STREAK` / `MAX_EFFICIENCY` | 異常値の足切り |
| `DAILY_SUBMIT_LIMIT` | 1台あたりの1日の送信回数 |
| `MAX_NAME_LENGTH` | 名前の最大文字数 |
| `TOP_COUNT` | 上位何位まで返すか |

**URLは変わりません**ので、ゲーム側の修正は不要です。

## 荒らされた場合

シートの該当行を削除すれば消えます。ひどい場合は **デプロイ → デプロイを管理 → アーカイブ** で一旦止められます。
