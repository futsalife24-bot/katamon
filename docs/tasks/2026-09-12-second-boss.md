## 完成した仕様

| 比較項目 | 第1ボス：超大型要塞戦車 | 第2ボス：雷晶龍ヴォルテリス |
|---|---|---|
| 姿・位置 | 鋼鉄の地上要塞 | 藍色と雷晶の空中龍 |
| 部位 | 主砲・副砲・装甲・ミサイルポッド | 雷角・天翼晶・嵐翼晶・尾晶 |
| 攻撃 | 砲撃主体、覚醒後ミサイル | 扇状三連弾 → 蓄雷（無攻撃）→ 固定レーンへの落雷 |
| 狙う味方 | 巡回による対象選択 | 生存中で最も高い位置の味方を優先。復活ガードは既存優先規則を維持 |
| 弱点の開き方 | 部位破壊によるCORE露出 | 蓄雷後、翼晶破壊、HP半分の覚醒時に心核露出 |
| ステージ | 要塞用の足場配置 | 雷雲の祭壇：高低差、壊せる上段足場、落雷を遮る足場 |
| 覚醒 | 要塞の第2形態 | 紫白色の電撃、落雷3本→4本。破壊済み部位は復活しない |

雷角を壊すと落雷の威力が下がる。両翼晶はそれぞれ落雷の威力・爆風を弱め、破壊時に心核を開く。尾晶破壊で三連結晶弾が単発になる。心核への直撃倍率はNORMAL 2.3 / HARD 2.0 / EXTREME 1.8。蓄雷後は味方全員に1巡の攻撃機会があり、翼破壊では破壊した巡回の残りと次の味方1巡で狙える。

専用ステージは2160×960。床と初期台座3か所は鋼鉄、残る4か所は破壊可能。落雷予告は固定の縦帯で表示し、移動で避けたり残った上段足場を遮蔽物に使える。本体画像の透明な余白には当たり判定を置かず、表示した部位と判定を合わせた。

- `sw.js`・表示BUILDを `v2.0.177-storm-boss` へ一致させ、新JSと実行画像をキャッシュ対象へ追加。
- `package.json`・`tests/`: 新規ルール/実戦/ブラウザQAを追加。既存ソース検査は選択式APIへ対応し、既存の動作検査は維持。
