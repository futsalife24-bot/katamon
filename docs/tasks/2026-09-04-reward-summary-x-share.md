# CPU報酬明細・結果共有・素材のみ受取

更新日: 2026-09-04

## 目的

通常のオフラインCPU BATTLEで、連勝報酬とステージ資源箱の素材内訳を結果画面から確認できるようにし、同じ集計結果を安全に共有できるようにする。あわせて、Gearが0個で素材だけの未受取報酬も既存の明示受取導線から確実に受け取れるようにする。

## 実装範囲

- 結果画面、タイトルから開く未精算画面、精算保存の再試行画面へ次の3区分を表示する。
  - 合計: Gear個数・粉末・設計片
  - 連勝報酬: 合計からステージ資源箱累計を除いた粉末・設計片
  - 資源箱（連戦累計）: CPU runへ即時保存済みの粉末・設計片
- 通常CPU 1vs1・公式ステージ・非ボス戦の結果画面だけに共有ボタンを置く。
- Web Share API対応端末ではOS共有を開き、非対応端末では`noopener noreferrer`付きの一時リンクからX Web Intentを新規タブで開く。キャンセル・失敗時に結果画面や報酬状態を変更しない。
- 共有文面は勝敗、最高連勝、精算見込み、資源箱累計、希少個体撃破の有無だけで組み立てる。
- 素材のみの未受取報酬を既存Drop Revealへ表示し、既存のlock・台帳・読戻しを通る「受け取る」操作だけで確定する。
- Gear 0個の素材のみ精算は物理倉庫の空きを消費しないため、内容確定後の精算時だけ`physical_storage_full`を除外する。未受取10件上限と未知の拒否理由は従来どおり維持する。

## 非対象・安全境界

- 報酬テーブル、CPU run保存形式、Gear保存形式、snapshot、ONLINE wire、Firebase Rules / Consoleは変更しない。
- ONLINE、協力、演習、チュートリアル、ボス、カスタム戦には結果共有を出さない。
- プレイヤー名、相手名、部屋ID、device/rival/run/reward/Gear ID、seed、通信ログ、query/hashを共有文面へ含めない。
- 共有描画だけでは外部通信せず、ユーザーが共有ボタンを押した時だけ共有先を開く。
- 素材0・Gear 0の空報酬は未受取一覧へ出さない。
- 実機GOAL QAはこの作業では開始しない。

## 完成条件

- 新旧previewで内訳が安全に算出され、旧intentは資源箱0として表示できる。
- 勝利・敗北・再読込pendingでも合計と内訳が一致する。
- 共有成功、キャンセル、失敗、Web Share非対応、安全なXリンク起動、起動不能、二重タップでゲーム状態と保存値が変わらない。
- 素材のみ報酬を閉じて再表示でき、受取後は素材だけが一度加算され、pending削除とledger登録が成立する。
- 既存のGear付きDrop Reveal、ONLINE/Firebase境界、PWA cache、全自動テストが回帰しない。
- `BUILD_ID`と`CACHE_VERSION`を同じ版へ上げ、CI成功後にGitHub Pagesの自動公開を確認する。
