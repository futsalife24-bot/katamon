## master監査

### そのまま再利用するもの

- Firebase匿名認証、REST/SSE、リース、presence、部屋ID、4席ロビー。
- 0.25秒/8px刻みの移動同期と、停止時の最終位置送信。
- 固定物理刻み、風、投射物、地形破壊、4ユニットの描画・スナップショット。
- ボス用の演出・地形素材、Stageの鉄地形、キャラクターカタログ。
- 端末内進捗の正規化・保存方針、既存必殺技DEMO基盤。

### 分離しないと競合するもの

- 通常2vs2の交互手番・投射物・着弾・カメラ・HUD・操作盤は協力戦でも正本として再利用できる。協力戦は4席を同じ味方陣営にし、5体目の要塞だけを敵へ追加する。
- `database.rules.json`は通常部屋の型とメッセージ種別だけを許可しており、協力用スナップショットを通せない。
- 現行CPUボスは連勝用の強化CPUで、固定要塞・部位・CORE・Phase2とは別物。
- 既存実績はキャラ解放向けで、18実績の段階報酬・未受取コイン・ショップ在庫を持たない。

### 新しく必要な境界

- Firebase: `coopOpen`/`coopRooms`の独立名前空間。複数人戦では通常対戦パケットを`net`の外包みで中継し、空席AIと要塞はホストだけが操作する。ソロ＋CPU3体は同一端末が全権威を持つため戦闘パケットを送らない。
- 端末保存: `katamon_coop_mvp_v1`。既存勝利数等は複製せず参照し、財布・永久所持・装備・協力統計だけを追加。
- テスト: 通常ターン順、実弾の飛翔と着弾後ダメージ、Rules、5体スナップショット、平坦鋼鉄、ダウン/アイテム、報酬/購入、通常回帰、ブラウザE2E、実機QA。
- 公開前: Rules変更をFirebase Consoleへ反映し、Android/iPhoneで凍結仕様のQAを完了する。

## 承認済み仕様変更

### 救助弾の使用回数（2026-08-22）

- 元資料「# 23. 救助弾」の「1試合2回」を上書きし、**1人につき1試合1回**とする。
- 1回使用後は同じ試合中に再使用できない。次の試合・再戦開始時は1回へ戻す。
- 初期所持、最大HP30%での復活、復活ラウンドは行動しない等、使用回数以外の仕様は変更しない。

### ライブ戦闘を通常2vs2の延長へ統一（2026-08-23）

- 旧協力Surfaceはライブ起動経路から外す。一斉攻撃はソロ＋CPU3体だけで、通常対戦の通常弾／必殺の照準と弾道を束ねる。
- 味方4体＋右側の大型要塞1体を、通常対戦と同じ`units`、固定物理刻み、投射物、着弾、手番終了へ載せる。
- 露出COREは貫通弾専用にせず、見えているCOREへ正しく到達する通常弾も外殻の開口部を通す。COREを外した弾は従来どおり装甲へ当たる。
- 部位と露出COREの狙点サイトは実際の当たり判定サイズを示し、スマホでも照準先を判別できる強さで表示する。
- 入力順は`P1 → P2 → P3 → P4`、4体READY後に通常弾／必殺を約150ms間隔で発射し、全弾解決後だけBOSSへ渡す。内部IDは`p1 → e1 → p2 → e2 → boss1`で固定する。
- 地形は2160×960へ大型化し、壊れない鋼鉄地面と高さの異なる空中足場5つを置く。初期配置に使う3台座だけ鋼鉄、移動用2足場は砲撃で壊れる。要塞前は射線と移動空間を確保する。
- 跳躍は全モードで自分の手番開始時に使用可能へ戻す。着地後の移動不能は従来どおり次の自手番まで残るため、通常は実質2手番に1回となる。2手番のチャージ制にはせず、将来デバフを解除した場合は同じ手番中に跳躍できる余地を残す。
- HUD、下部操作盤、初期カメラ倍率、横ドラッグ、発射操作は通常2vs2と同じ実装を使う。全景へ強制縮小しない。協力戦ではミニマップだけを外し、視点距離スライダーは全モードでHUD下の戦場側へ移す。
- ソロ＋CPU3体で出撃できる。人間が1人だけの試合は不要なFirebase戦闘通信を行わず、出先スマホでも単独確認できる。
- ホストは作戦準備室で、空席を担当するP2・P3・P4の味方AIモンスターを席ごとに選択できる。人間が着席した場合は本人の選択を優先する。
- 協力ボス入口と作戦準備室では、通常ONLINEと同じルームBGMを維持する。閉じた時だけタイトル曲、戦闘開始時だけ要塞戦BGMへ切り替える。
- 制限はNORMAL 20ラウンド（最大100手）、HARD 15ラウンド（75手）、EXTREME 12ラウンド（60手）。HPと部位狙いの価値は変えない。

### 装甲・狙点・Phase 2（2026-08-23）

- ボス画像の透過外接四角ではなく、車体矩形と砲塔・装甲・ミサイルポッドの固定円を合成した端末共通判定を使う。
- 直接着弾45は、装甲本体30、部位HP45＋本体18、露出COREは難易度倍率（NORMAL 2倍、HARD 1.75倍、EXTREME 1.5倍）で解決する。地面から届く爆風は通常戦の距離減衰を維持する。
- Phase 1の連装砲・主砲・前面装甲を破壊するとCOREが開く。NORMAL/HARDは2要塞ラウンド、EXTREMEは1要塞ラウンドで閉じる。
- HP50%以下になった次の要塞手番は攻撃せずPhase 2変形へ消費する。ミサイルポッド解禁、CORE再露出、攻撃プロファイル、画像、警告カットイン、BGMを同じ同期境界で切り替える。
- 連装砲・主砲の破壊は要塞砲を弱体化し、Phase 2のミサイルポッド破壊は強化ミサイルを通常砲へ戻す。部位狙いを単なる追加HPにしない。
- 一斉行動は通常弾・ゲージMAXの必殺・跳躍・救助弾を選択できる。複数必殺は全員のキャラ位置へ0.9秒のオーラを同時表示してから、既存キャラ絵を0.16秒差で順次表示し、全員が同じ画面へ揃う2.37秒の黒鉄・真鍮カットインを1回挟む。「同時必殺」を大型表示し、演出終了後だけ各行動を予約順に発射する。SUBと救助以外のCO-OP ITEMはREADY中に使用できず、先頭弾で撃破しても予約行動を最後まで解決する。複数人戦は専用同期を導入するまで従来の逐次手番を維持する。
- 戦闘メニューの「タイトルへ戻る」はロビーを再表示せず、ホストなら部屋、参加者なら自席を片付けてタイトルへ戻る。リザルトの「ロビーへ戻る」は従来どおり作戦準備室へ戻す。

### 要塞次弾予告・救助直後保護（2026-08-23）

- 要塞の標的は距離順で同じ相手を狙い続けず、各要塞ラウンドで生存席を順番に巡回する。戦場と手番バーへ攻撃種・次弾対象を事前表示する。
- 救助された本人は同じ味方巡回に未消化手番があっても待機し、他に生存者がいる間は直後の要塞砲撃対象から外す。次の味方巡回で本人の手番が来た時に保護を解除する。
- 保護対象しか生存していない場合は要塞の標的になり得る。永続無敵や全滅判定の回避には使わない。
