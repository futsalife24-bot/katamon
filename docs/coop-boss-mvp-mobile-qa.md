# 協力ボスMVP Android / PC 実機QA

## 開始条件

- 協力ボスMVPの積み上げPRを順番どおり統合した検証版である。
- `BUILD_ID`と`sw.js`が同じ版で、端末側もその版を表示している。
- `database.rules.json`をFirebase Realtime Database Rulesへ反映済みである。
- 公開機能フラグはOFFのまま、検証URLだけ`?coopMvp=1`で起動する。
- 通常ONLINE用の`rooms` / `open`と、協力用の`coopRooms` / `coopOpen`が混ざっていない。

## 端末構成

| 記号 | 端末 | 主な役割 |
|---|---|---|
| A | Android Chrome | ホスト |
| B | PC Chrome通常 | 参加者・再接続確認 |
| C | PC Chromeシークレット | 3人目 |
| D | 別PCまたは追加ブラウザープロファイル | 4人目 |

iPhoneは現在の手元環境にないため必須端末へ含めない。将来用意できた時だけSafari確認を追加する。

各試験で、画面・Firebase `coopRooms/{roomId}`・Consoleエラーを同時に記録する。

## 必須シナリオ

### 1. 人数とAI補充

- [ ] 1人＋AI補充ONで、空席3つがAIになり出撃できる（出先スマホの単独確認用）。
- [ ] ホストがP2・P3・P4の味方AIモンスターを個別に選び、選んだ3体が席どおり出撃する。
- [ ] 人間が入った席は本人の選択が優先され、退出して空席へ戻るとホストが選んだAIモンスターへ戻る。
- [ ] 2人＋AI補充ONで、空席2つがAIになり出撃できる。
- [ ] 3人＋AI補充ONで、空席1つがAIになり出撃できる。
- [ ] 4人で、全員のキャラ・装備・準備状態が一致して出撃できる。
- [ ] AI補充OFFでは、着席していない枠を戦闘へ出さない。
- [ ] AIは可能な範囲でキャラ重複を避け、画面上で`[AI]`と判別できる。

### 2. 通常2vs2物理を使う一斉攻撃

- [ ] ソロ＋CPU3体ではP1→P2→P3→P4の順に通常弾／必殺／跳躍／救助弾を照準し、READY 4/4後に約150ms間隔で4行動が飛ぶ。
- [ ] ゲージMAXの味方が複数必殺を選ぶと、参加者全員のオーラが0.9秒同時に立つ。その後、既存キャラカットインが約0.16秒差で1体ずつ飛び込み、全員が2.37秒の同一画面へ揃う。大型の`同時必殺`が読め、共通SEは音割れせず1回だけ鳴る。
- [ ] READY中に跳躍すると着地点へ移り、救助弾はダウン中の味方だけを復活させ、各使用権を1回だけ消費する。SUBと救助以外のCO-OP ITEMは誤作動しない。複数人戦は専用同期導入まで逐次手番を維持する。
- [ ] 戦闘メニューからタイトルへ戻ると作戦準備室が再表示されず、再入場時に古い部屋状態が残らない。リザルトのロビー戻りは従来どおり機能する。
- [ ] 協力ボス入口・作戦準備室ではタイトル曲へ戻らずルームBGMが続き、画面を閉じるとタイトル曲、出撃すると要塞戦BGMへ切り替わる。
- [ ] 指を離した後に実弾が飛び、命中または地形着弾してからだけHPが変化する。
- [ ] 先頭弾でボスHPが0になっても予約した残りの弾が飛び切り、全弾・爆発・落下後にだけ勝敗が確定する。
- [ ] 発射前、飛翔中、着弾、ダメージ表示、次手番カットインを目で追える。
- [ ] 2160×960を1画面へ押し込まず、通常倍率で開始して縦横ドラッグと自動追従が使える。
- [ ] 協力戦ではミニマップが消え、現在手番キャラの頭上に`▼`が表示される。
- [ ] 視点距離スライダーはHUDと操作盤の間の戦場側にあり、跳躍・CO-OP ITEM・必殺・SUB・左右移動の各ボタンが重ならず押せる。
- [ ] 全端末でボスHP、味方HP、手番、風、位置、発射、着弾結果が一致する。
- [ ] 途中参加者向けの開始データ再送で、進行中の試合がTURN 1へ巻き戻らない。

### 3. 現行4vs1・支援・生存

- [ ] 通常弾・必殺技・橙のSUB照準が見分けられる。
- [ ] 大型要塞が右側に1体だけ存在し、直接着弾45は装甲本体30、部位45＋本体18、露出COREはNORMALで90になる。
- [ ] ボス弾も実弾として右から左へ飛び、着弾後だけ味方HPを減らす。
- [ ] 専用地形は鋼鉄地面＋高さの異なる空中足場5つで、跳躍によって各段へ移れる。
- [ ] 初期配置用3台座は砲撃後も壊れず、移動用2足場だけ通常弾・必殺・ボス弾で壊れる。
- [ ] 要塞前に十分な射線と移動空間があり、見た目と接地判定が一致する。
- [ ] 跳躍は各自手番の開始時に戻るが、跳躍着地後の次手番は移動不能のため再使用できず、その次の手番で再び使える。
- [ ] 連装砲・主砲・前面装甲を狙って破壊でき、3部位の破壊またはゲージ到達でCOREが開く。
- [ ] NORMALのCOREは2回の要塞行動まで開き、露出中の直撃だけ2倍になる。
- [ ] HP50%以下の次の要塞手番で攻撃せずPhase 2へ変形し、画像・警告・CORE・BGMが全端末で同時に切り替わる。
- [ ] Phase 2のミサイルポッドが有効な間は強化ミサイルになり、破壊後は通常砲へ戻る。
- [ ] 回復弾、弱体化弾、救助弾を各1回以上成功させる。
- [ ] 各プレイヤーの救助弾は1試合1回だけ使え、使用後は同じ試合で再選択できない。
- [ ] ダウン中は入力待ちで試合を止めず、AIまたは味方が救助できる。
- [ ] 救助された本人は同じ味方巡回の残り手番を取らず、他に生存者がいる間は直後の要塞砲撃対象にならない。
- [ ] 戦場の赤い照準枠と手番バーに、要塞の次弾対象・攻撃種が一致して表示される。
- [ ] DEAD LINE救済と全滅敗北が仕様どおり動く。

### 4. 切断・復帰・ホスト中断

- [ ] Bを機内モード等で切断し、約9秒後からホストAIが状態を引き継ぐ。
- [ ] Bが同じ部屋へ戻り、HP・燃料・使用回数を巻き戻さず次の自席手番から復帰する。
- [ ] ホストAを切断しても別端末へホスト移譲しない。
- [ ] ホストが90秒以上復旧しない場合、着席中の参加者は無報酬でロビーへ戻る。
- [ ] ホスト安全中断ではコイン・初回クリア・実績を付与しない。

### 5. 結果・報酬・再戦

- [ ] 勝利／敗北、難易度、獲得コイン、部位破壊、救助、初回、実績が読める。
- [ ] 同じ試合を再表示しても報酬が二重付与されない。
- [ ] 15秒以内にホストを含む2人以上が希望すると同条件でロビーへ戻る。
- [ ] 再戦開始時、各プレイヤーの救助弾が1回へ戻る。
- [ ] 再戦非希望者の席だけ受付終了後に空き、参加者を補充できる。
- [ ] 希望者が1人以下なら全員ロビーへ戻り、報酬を重複させない。

### 6. ショップ・実績・通常回帰

- [ ] 18実績、カタコイン残高、9商品、3コスメが再読込後も保持される。
- [ ] 未所持品は装備できず、購入時だけ残高が減る。
- [ ] 機能フラグOFFではCO-OP BOSSが表示されない。
- [ ] 通常ONLINE、CPU BATTLE、演習、チュートリアルが従来どおり動く。

## 表示品質

- [ ] 右端の要塞が560×372相当の迫力で表示され、排煙・粉塵・機関室・主砲・油圧の待機演出中も部位狙点と見た目がずれない。
- [ ] 高所2枚を含む破壊可能4足場へ跳躍でき、初期配置の鋼鉄3台座だけは壊れない。
- [ ] Android縦画面とPCの縦長表示で横はみ出し・文字重なり・押せないボタンがない。
- [ ] 火山背景、黒鉄・真鍮の操作盤、羊皮紙／木板系UI、既存キャラ素材の世界観が統一されている。
- [ ] 巨大要塞が味方より十分大きく、横スクロール先で全体を確認できる。
- [ ] 照準中の弾道ガイドが要塞画像の裏へ隠れず、着弾候補まで読める。
- [ ] 画面上端に空の金枠が常駐せず、実績通知が出た時だけ表示される。
- [ ] リザルト中に移動・武器操作が残らず、戻る／再戦の選択へ集中できる。
- [ ] Console error、画面エラー、Firebase permission deniedがない。
