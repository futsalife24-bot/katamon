# 協力ボスMVP Android / iPhone 実機QA

## 開始条件

- 協力ボスMVPの積み上げPRを順番どおり統合した検証版である。
- `BUILD_ID`と`sw.js`が同じ版で、端末側もその版を表示している。
- `database.rules.json`をFirebase Realtime Database Rulesへ反映済みである。
- 公開機能フラグはOFFのまま、検証URLだけ`?coopMvp=1`で起動する。
- 通常ONLINE用の`rooms` / `open`と、協力用の`coopRooms` / `coopOpen`が混ざっていない。

## 端末構成

| 記号 | 端末 | 主な役割 |
|---|---|---|
| A | Android Chrome | ホスト |
| B | iPhone Safari | 参加者・再接続確認 |
| C | PC Chrome通常 | 3人目 |
| D | PC Chromeシークレット | 4人目 |

各試験で、画面・Firebase `coopRooms/{roomId}`・Consoleエラーを同時に記録する。

## 必須シナリオ

### 1. 人数とAI補充

- [ ] 2人＋AI補充ONで、空席2つがAIになり出撃できる。
- [ ] 3人＋AI補充ONで、空席1つがAIになり出撃できる。
- [ ] 4人で、全員のキャラ・装備・準備状態が一致して出撃できる。
- [ ] AI補充OFFでは、着席していない枠を戦闘へ出さない。
- [ ] AIは可能な範囲でキャラ重複を避け、画面上で`[AI]`と判別できる。

### 2. 同時入力と決定的進行

- [ ] 30秒入力中、各端末が独立して移動・武器・照準を選べる。
- [ ] 指を離すとREADYになり、そのラウンドでは再入力できない。
- [ ] 全員確定後、P1→P2→P3→P4の固定順で約0.15秒間隔の砲撃になる。
- [ ] 1人が未確定なら30秒で自動確定し、試合が停止しない。
- [ ] 全端末でボスHP、部位、CORE、味方HP、ラウンド、風が一致する。

### 3. ボス・支援・生存

- [ ] 通常弾・必殺技・橙のSUB照準が見分けられる。
- [ ] 部位破壊が反映され、CORE露出からPhase 2へ移行する。
- [ ] ボス4技の警告・対象・ダメージが全端末で一致する。
- [ ] 回復弾、弱体化弾、救助弾を各1回以上成功させる。
- [ ] ダウン中は入力待ちで試合を止めず、AIまたは味方が救助できる。
- [ ] DEAD LINE救済と全滅敗北が仕様どおり動く。

### 4. 切断・復帰・ホスト中断

- [ ] Bを機内モード等で切断し、約9秒後からホストAIが状態を引き継ぐ。
- [ ] Bが同じ部屋へ戻り、HP・燃料・使用回数を巻き戻さず次の入力ラウンドから復帰する。
- [ ] ホストAを切断しても別端末へホスト移譲しない。
- [ ] ホストが90秒以上復旧しない場合、着席中の参加者は無報酬でロビーへ戻る。
- [ ] ホスト安全中断ではコイン・初回クリア・実績を付与しない。

### 5. 結果・報酬・再戦

- [ ] 勝利／敗北、難易度、獲得コイン、部位破壊、救助、初回、実績が読める。
- [ ] 同じ試合を再表示しても報酬が二重付与されない。
- [ ] 15秒以内にホストを含む2人以上が希望すると同条件でロビーへ戻る。
- [ ] 再戦非希望者の席だけ受付終了後に空き、参加者を補充できる。
- [ ] 希望者が1人以下なら全員ロビーへ戻り、報酬を重複させない。

### 6. ショップ・実績・通常回帰

- [ ] 18実績、カタコイン残高、9商品、3コスメが再読込後も保持される。
- [ ] 未所持品は装備できず、購入時だけ残高が減る。
- [ ] 機能フラグOFFではCO-OP BOSSが表示されない。
- [ ] 通常ONLINE、CPU BATTLE、演習、チュートリアルが従来どおり動く。

## 表示品質

- [ ] Android縦画面とiPhone縦画面で横はみ出し・文字重なり・押せないボタンがない。
- [ ] 火山背景、黒鉄・真鍮の操作盤、羊皮紙／木板系UI、既存キャラ素材の世界観が統一されている。
- [ ] 巨大要塞が味方より十分大きく、部位とCOREを狙える。
- [ ] リザルト中に移動・武器操作が残らず、戻る／再戦の選択へ集中できる。
- [ ] Console error、画面エラー、Firebase permission deniedがない。
