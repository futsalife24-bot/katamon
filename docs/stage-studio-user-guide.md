# Stage Studio 利用ガイド

Stage Studioは、スマートフォンだけで対象ゲーム用ステージを作成、検証、共有できるWebアプリや。アカウント、PC、開発環境、AIサービスは必要ない。

このガイドはStage Studio `1.5.0-font-system`に対応している。

## 1. 開き方

公開版は次のURLから直接開ける。インストールしなくてもSafariまたはChromeから利用できる。

https://futsalife24-bot.github.io/katamon/tools/stage-studio/

初回だけアプリ本体の読み込みに通信が必要。読み込み後は、対応ブラウザならオフラインでも下書き編集を続けられる。プライベートブラウズでは端末保存が消えやすいため、通常タブを推奨する。

### iPhone Safari

1. SafariでStage Studioを開く。
2. 画面下の共有ボタンを押す。
3. `ホーム画面に追加`を選ぶ。
4. 名前を確認して`追加`を押す。
5. ホーム画面のアイコンから起動する。

`ホーム画面に追加`が見つからない場合は、共有メニュー下部の`アクションを編集`を確認する。iOS・iPadOS 17以降の現行安定版を正式対象とする。

### Android Chrome

1. ChromeでStage Studioを開く。
2. アプリ内の`アプリとしてインストール`、またはChromeのメニューを開く。
3. `アプリをインストール`または`ホーム画面に追加`を選ぶ。
4. 確認画面でインストールする。

インストール案内が出なくても、通常のChromeタブから全機能を利用できる。Android 12以降の現行安定版を正式対象とする。

## 2. 新しいステージを作る

画面下の工程は`ホーム / 新規 / 生成 / 地形 / 出撃 / テスト / 検証 / 共有`の8つ。背景などの見た目は`地形`、風は`テスト`にまとまっている。ホームでは`利用方法`が常に表示され、その後にストレージ使用量や軽量表示を確認する`端末の状態`が続く。

`地形`、`出撃`、`テスト`のマップ外に`横画面`ボタンがある。Android Chromeやインストール済みPWAで自動回転が許可されている場合は、ボタンを押すと横向き固定を試みる。iPhone Safariなど自動固定できない環境では案内が表示されるため、画面回転ロックを解除して端末を横へ向ける。横画面では主要な編集・配置・テスト操作がマップ右側へ移り、マップを見たまま操作できる。`縦画面`ボタンを押した場合も、端末側の制限で自動復帰できなければ端末を縦へ戻す。

1. ホームの`新しいステージを作る`を押す。
2. ステージ名、作成者表示名、説明を入力する。
3. `白紙`または`プリセット`を選ぶ。
4. プリセットでは型とシードを決め、`この設定で生成`を押す。

シード、生成器バージョン、プリセット、生成設定が同じなら、対応端末で同じ地形を再現できる。生成後は必ず手動編集できる。

MVPのワールド幅と編集領域は対象ゲームに合わせて固定される。地形の下端は落下死亡線より下へ伸びない。

## 3. 地形と見た目を編集する

地形画面はマップを一番上に置き、ステージ画像の中には操作ボタンを重ねない。マップ直下の`選択中`ボタンを押すと、`描く / 削る / キャラ / 塗る / 線 / 四角 / 円 / ロック`の一覧が開く。使うツールを選ぶと一覧は自動で閉じ、`選択中`の表示が切り替わる。`戻す / 選択中 / 進む`は常に同じ1段で操作できる。

`横画面 / 倍率 / 設定`もマップ外の操作帯にある。ブラシサイズなどの細かな設定は初期状態で隠れており、`設定`を押すと前面へパレットが開く。`ブラシ / 整形 / 表示 / 見た目`を切り替え、値を変更するか整形処理を実行するとパレットは自動で閉じる。続けて設定する時は再度`設定`を押し、すぐ閉じたい時は`閉じる`を押す。パレット内だけをスクロールするため、元の画面が裏で動かない。

- 一本指: 選択中ツールで描く、削る、配置する。
- 二本指: キャンバスを移動し、ピンチで拡大縮小する。
- `−` / `＋`: ピンチを使わず拡大縮小する。
- `全体`: ステージ全体を表示する。
- `戻す` / `やり直す`: 直前の操作をUndo/Redoする。
- `ツールをロック`: 誤操作を避けたい時に使う。

編集キャンバス以外では通常どおりページをスクロールできる。細すぎる地形には検証時に警告が出る。

`地形`画面では草原、砂漠、雪原、火山の既存背景、背景色・グラデーション、地形色、明るさ、装飾表示を設定できる。Canvasには対象ゲームと同系統の背景画像、地形の縁・地層・石・ノイズが表示され、`出撃`と`テスト`にも同じ見た目が引き継がれる。背景画像のアップロードや外部画像URLはMVPでは利用できない。

`キャラ`を選ぶと、対象ゲームと同じ寸法のキャラクターガイドを地形上でドラッグできる。これは足場の厚みや空間を確認するための編集補助で、下書きの編集状態には保存されるが、共有する正規ステージデータには含まれない。キャラクターの当たり判定が地形へ重なる、または画面外へ出ると赤色とメッセージで警告される。

赤いキャラクターがある時だけ`赤いキャラを安全位置へ`を押せる。押すと、赤いガイドだけを現在位置に最も近い接地可能な足場へ移動する。地形がなく安全位置を見つけられない場合は移動せず、日本語メッセージで知らせる。この操作も`戻す`と`やり直す`を利用できる。

MVPで使える地形素材は`通常（破壊可能）`だけ。`壊れない鋼鉄（準備中）`はゲーム本体対応後のための無効表示で、選択、下書き保存、JSON/ZIP出力、ゲームへのインポートはできない。氷、沼、跳ねる床、ダメージ床等も対象ゲーム側が未対応のため、出力データへは含まれない。

## 4. 出撃地点を置く

1. 下部メニューの`出撃`を開く。
2. `2人（1対1）`または`4人（2対2）`を選ぶ。
3. 配置したいスロットを選び、キャンバスの地面付近をタップする。
4. 必要なら`安全な位置へ自動配置`を使う。

出撃地点は地面へ吸着する。画面外、地形内部、他の出撃地点との重なり、地面がない場所はエラーになる。崖へ近い、頭上が狭い、高度差が大きい場所は警告になる場合がある。

## 5. 風を設定してテストプレイする

MVPで利用できるギミックはステージ全体の風だけ。

1. `テスト`画面を開く。マップ直下の操作帯に`左へ移動`、`テスト砲撃`、`右へ移動`、`リセット`、砲撃角度、威力がまとまって表示される。
2. 砲撃角度と威力を調整する。
3. 必要なら操作帯の下にある風の詳細設定で、有効・無効、向き、強さを調整する。無風にする場合は風を無効にする。
4. 左右移動でキャラクターの接地と落下を確認する。
5. `テスト砲撃`を押す。
6. 弾道、着弾、爆発範囲、地形破壊、風の影響を確認する。
7. `リセット`で編集開始時の状態へ戻す。

スマートフォン縦画面ではマップと操作帯が一体の固定表示になるため、移動や砲撃を操作する間もマップを見失わない。風の詳細設定だけを下へ分け、主要操作をマップから離さない構成にしている。

テスト砲撃は対象ゲームと同じ重力、風、初速倍率、120Hz固定ステップ、地形グリッドを使う。特殊技全種類を再現する完全な試合シミュレーターではない。

## 6. 検証する

共有前に`検証`画面の`ステージを自動検証`を押す。

- エラー: 修正するまで出力・インポートできない。
- 警告: 公平性や遊びやすさの参考。意図した特殊ステージなら保存できる。

## 7. 保存と再開

編集内容は操作後にIndexedDBへ自動保存される。ホームでは最近の下書き、保存日時、件数、使用量を確認できる。

1. ホームの`下書きから再開`、または一覧のステージを選ぶ。
2. 読み込み後、最後に開いていた工程から編集を続ける。
3. 名前変更、複製、削除は対象の下書きだけへ作用する。

ブラウザやOSが端末内データを整理する場合に備え、作業の節目でJSONまたはZIPをファイルへ保存する。

## 8. JSON・ZIPを書き出す

1. `検証`でエラーがないことを確認する。
2. `共有`画面で、ステージ名、作成者、対応バージョン、警告件数、ハッシュを確認する。
3. 画像を含まない軽量な共有には`JSONを書き出す`を選ぶ。
4. まとめたバックアップには`ZIPを書き出す`を選ぶ。

ファイル名は安全な文字へ変換され、`.stage.json`または`.stage.zip`で保存される。

## 9. LINE・Discord・メール・AirDropで共有する

端末がファイル付きWeb Shareに対応している場合は`共有シートを開く`を使う。このボタンは軽量なJSONファイルを共有シートへ渡す。表示された共有先からLINE、Discord、メール、AirDrop等を選ぶ。

ZIPを共有したい場合は、先に`ZIPを書き出す`で端末へ保存し、共有先アプリのファイル添付から選ぶ。

共有シートが利用できない場合：

1. `JSONを書き出す`または`ZIPを書き出す`でファイルへ保存する。
2. LINEやDiscord等のアプリを開く。
3. 添付ボタンから`ファイル`を選ぶ。
4. 保存した`.stage.json`または`.stage.zip`を添付する。

iPhoneでは`ファイル`アプリ、Androidでは`Files`等へ保存される。JSONが小さい場合は`JSONをコピー`も使える。共有機能は事前に機能検出され、利用できないボタンを押して初めて失敗する設計にはしない。

## 10. 受け取ったステージをStage Studioで開く

1. ホームの`ステージをインポート`を押す。
2. `.stage.json`または`.stage.zip`を選ぶ。
3. スキーマ、サイズ、危険データ、対応バージョン、ハッシュの検査を待つ。
4. 問題がなければ新しい下書きとして保存する。

同じ表示名でも、内部IDまたは内容ハッシュが異なる場合は別ステージとして扱われる。

## 11. 対象ゲームへインポートする

1. 対象ゲームを開く。
2. タイトルから`演習`を開き、演習設定の`カスタムステージ`管理を開く。
3. `ステージをインポート`を押す。
4. Stage Studioから保存したJSONまたはZIPを選ぶ。
5. プレビュー、ステージ名、作成者、人数、警告、容量、`contentHash`を確認する。
6. `保存`を押す。

インポートだけでは公式ステージを書き換えない。エラーになった場合、既存のカスタムステージも変更されない。

## 12. カスタムバトルで使う

1. `カスタムバトル`を選ぶ。
2. ステージ選択で`カスタム`タブを開く。
3. インポート済みステージを選ぶ。
4. `stageId`、スキーマ、ハッシュ、対応バージョンを確認する。
5. 人数とキャラクターを選び、バトルを開始する。

カスタムステージはカスタムバトル、プライベート対戦、テスト用途に限定される。通常のランダムステージや公式対戦へは追加されない。試合終了後は通常の公式ステージを再び選べる。

### プライベートオンライン対戦で使う

1. ホスト端末で対象ゲームのオンライン対戦を開き、部屋を作る。
2. ロビーの`カスタムステージを選ぶ`を押す。
3. 保存済みステージを選び、`このステージをオンラインで使う`を押す。
4. ステージ名と対戦人数を確認し、全参加者が準備完了したら`対戦開始`を押す。
5. 参加者側でステージ本体、256KB上限、`stageId`、`schemaVersion`、`contentHash`、`gameCompatibility`が自動検証される。
6. バトル画面へ移り、全プレイヤーの検証成功通知が揃った後に操作できるようになる。

参加者側への事前インポートは不要。改ざんや版違いがある場合は試合を開始せず、日本語のエラーを表示する。全員が同じ最新版の対象ゲームを開いて利用すること。カスタムステージはプライベートな部屋だけで使われ、通常のランダム対戦やランキングへは混入しない。オンライン共有できるステージ本体は256KBまでで、外部画像や任意コードは送信しない。

## 13. バックアップと復元

- 定期バックアップ: `共有`画面からJSONまたはZIPを書き出す。
- 復元: ホームまたは`共有`画面のインポートからバックアップを選ぶ。
- 端末移行: 旧端末でファイル出力し、新端末へ共有してインポートする。
- 削除前: 必要なら先にJSONまたはZIPを保存する。

端末内保存は便利やけど永久保存の保証はない。長く残したいステージはファイルでも保管する。

## 14. エラー時の対応

| 表示・症状 | 対応 |
|---|---|
| スキーマが対応外 | 新しいStage Studioまたは対応する対象ゲームで開く |
| ハッシュ不一致 | 破損・改変の可能性があるため、送信元から再共有してもらう |
| ファイルが大きすぎる | 背景等を除いたJSON形式を使う。MVPは利用者画像を含めない |
| 出撃地点が不正 | `安全な位置へ自動配置`を使って再検証する |
| 地形が細すぎる | 警告箇所を太くする。意図した形なら警告のまま保存可能 |
| 端末保存に失敗 | 空き容量を確認し、JSONへ書き出してから不要な下書きを整理する |
| 共有シートが出ない | ファイルへ保存し、共有先アプリから添付する |
| オフラインで初回起動できない | 一度オンラインでアプリ本体を開いてから再試行する |
| 更新通知が出た | 編集内容が自動保存されたことを確認し、`下書きを保存して更新`を押す |

不明なファイルを無理に開いたり、拡張子だけを書き換えたりしない。インポート失敗時は安全のため処理を中断する。
