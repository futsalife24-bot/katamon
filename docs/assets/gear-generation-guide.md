# CATAMON Gear画像生成ガイド

## 正本構成

Gear画像は次を合成して表現する。

- 共通スロット外枠: 1形状。配置差は回転のみ。
- 部位シルエット: 6種。
- セット紋章: 8種。
- 完成済み組み合わせ画像: 作らない。

## 部位シルエット

| slot | 役割を示す主形状 |
|---|---|
| auxiliary | 補助アーム、工具、支援装置 |
| sight | 大型レンズ、測距器、調整ノブ |
| engine | タービン、排気、駆動輪、低重心 |
| barrel | 太い砲口、短い砲身、発射機構 |
| armor | 厚い装甲板、広い防御面、重い縁 |
| core | 中心核、発光炉、対称安定器 |

全シルエットに、紋章を差し替えるための空の六角ソケットを持たせる。ソケットへ文字や固定セット記号を描かない。

## セット紋章

| set | 色以外の形状言語 |
|---|---|
| assault | 横へ突進する鏃と短い顎刃。翼型にしない |
| life | 心臓型生命核と葉 |
| fortify | 城壁、厚い盾、リベット |
| critical | 円形照準環、調整ノブ、十字レティクル |
| blast | 圧力球と放射リング |
| impact | ピストン、ばね、衝突板 |
| rescue | 修理レンチ、支援翼、生命カプセル |
| last_stand | 非対称に割れた炉、非常クランプ、破断した格納環 |

## 共通生成制約

- 1画像1オブジェクト。
- 正方形1:1。
- 実alpha透過PNG。
- 背景、UI、文字、数字、CATAMON本体、外枠を含めない。
- くっきりした太い輪郭と大きな面で構成する。
- CATAMONの真鍮、装甲、かわいいデフォルメ機械の世界観へ合わせる。
- フォトリアル、現代兵器、細い壊れやすい形、過剰な微細装飾を避ける。

## プロンプト運用

部位シルエットは最初に承認した補機をスタイル参照にし、対象部位だけを差し替える。セット紋章は真鍮・黒鉄・太い輪郭を共通スタイルとし、セットごとに主シルエットを変える。猛攻・会心・背水は、それぞれ「横向き突撃刃」「円形照準器」「非対称の破損炉」を正本とし、同じ翼型へ戻さない。

透明チェッカーが画像へ焼き込まれる場合があるため、生成結果を見た目だけで採用しない。PNGを復号してRGBA・alpha最小値0・最大値255を確認する。

## バッチ監査

1. 文字なしで部位・セットを説明できる。
2. 64pxで瞬時に識別できる。
3. 27pxで紋章の輪郭差が残る。
4. モノクロでも隣接カテゴリと混同しない。
5. 1画像1オブジェクト、実透過、正方形を満たす。
6. 共通外枠と紋章を画像へ焼き込んでいない。
7. シルエットの空ソケットへ同じ紋章を合成できる。
