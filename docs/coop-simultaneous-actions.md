# 協力戦：同時準備と一斉発射

2026-09-12のユーザー指定を反映。第1ボス・第2ボス、ソロ＋AI、複数人戦に共通。
従来の「ソロのみ順次READY・150ms間隔発射」「複数人は逐次手番」を置き換える。

## 遊び方

- 味方の準備時間は全員共通で30秒。全員が同時に移動・照準できる。
- 従来の発射操作（引いて離す）で行動をREADYにする。READY後は移動と再入力を固定し、自分の確定した弾道を表示する。
- 通常弾、必殺、跳躍、救助・回復・弱体化弾、装備SUBを予約できる。装備・使用回数・ゲージ・移動禁止の条件を守る。1人1行動。
- 生存して行動可能な味方全員がREADYになると、30秒を待たず発射へ進む。AIも人間の入力待ちをせず移動・照準・READYする。
- 30秒を過ぎた未READYの味方はその巡回を待機する。未確定の照準を勝手に射撃へ変換しない。
- 発射する行動がある場合、発射直前にReady!（0.65秒）→Fire!（0.30秒）の共通合図を表示する。必殺技を含む場合はReady!→Fire!→キャラのオーラ→必殺技カットイン→一斉発射の順とする。合図中は入力と弾の生成・背景物理を止め、全員待機なら合図を省略する。
- 全弾を同じ固定物理tickで生成する。複数必殺の共通演出は維持する。全弾・跳躍・落下などの解決後にボスへ渡す。
- ダウン、行動不能、救助直後の待機は既存の状態条件を維持し、READY必須人数から除外する。
- メニューを開いても共通期限とオンライン進行は停止しない。

## 同期

ホストが準備開始・共通期限・受理した行動集合を確定する。時間は既存のサーバー時刻補正を使用し、ソロは端末時刻を使用する。
複数人では発射集合を送る時点から700ms後を共通開始時刻として指定する。通信がそれより遅い端末は受信後に再生を開始し、着弾後の既存state/resultで収束する。実ネットワーク上の画面表示が完全な同時刻になることまでは保証しない。

| 通信 | 送信者と用途 |
|---|---|
| salvoOpen | ホスト。準備前の盤面、対象席、30秒の期限 |
| salvoMove | 本人、または空席/引継ぎAIを担当するホスト。0.25秒間隔と停止時の座標・燃料 |
| salvoReady | 参加者。最終位置と確定した1行動をホストへ送信 |
| salvoAck | ホスト。受理したREADYを全員へ通知 |
| salvoFire | ホスト。発射集合、共通開始時刻、発射前の盤面、行動ID |

- 協力部屋の既存net外包みを利用。通常ONLINEのprotocol・Firebase Rules・保存schemaは変更しない。
- 世代と巡回番号、送信者と席、移動連番、燃料消費、座標、弾道、装備・残数を確認する。同じREADYは二度追加せず、期限後・過去巡回の入力を捨てる。
- 次の準備開始と発射通知は、既存の状態更新を追い越さない受信キューで適用する。
- 協力通信にsalvoVersion=1を付ける。旧クライアントとの混在は更新を案内して停止する。
- 固定物理とホストのstate/result検証を再利用する。最初の命中で撃破しても予約済み行動の解決までは決着を保留する。
- 両ボスの通信に必要なRTDBキー順と地形下端924px・破壊跡検証を統一する。
