# カタモン縦型PV 制作ルール

## 正本

- 設定の正本は`config/pv_config.yaml`。
- 入力素材は`input/`。読み取り専用として扱い、既存ファイルを上書きしない。
- 中間生成物は`temp/`、完成品は`output/`、レポートは`reports/`、ログは`logs/`へ出す。

## 安全ルール

- 権利不明な外部素材を取得しない。
- キャラクター画像を縦横別々に拡縮しない。常にアスペクト比を維持する。
- ウォーターマークを削除しない。
- 実装済みと確認できない機能を映像へ追加しない。
- 実プレイ録画ではない場面を、レポート上で実プレイと表現しない。
- 未提供のSNS名・URLを創作しない。プレースホルダーは設定に保持し、初期状態では描画しない。
- 元素材の削除、公開、投稿はユーザーの明示確認なしに行わない。

## ビルド手順

1. `node scripts/scan_assets.js`
2. `node scripts/build_preview.js`
3. `reports/qa_report_preview.md`と`temp/preview_qa_contact_sheet.png`を確認
4. 問題修正
5. `node scripts/build_final.js`
6. `reports/qa_report_final.md`と`temp/final_qa_contact_sheet.png`を確認

## 完成条件

- 56秒、9:16、30fps、黒帯なし。
- 最終版は1080×1920、H.264、AAC、yuv420p。
- 冒頭1秒以内にキャラクター移動または発射演出がある。
- テロップは原則15文字以内、Noto Sans JP、白またはアクセント色、黒縁。
- 重要情報は縦画面セーフエリア内。
- 黒画面、長い無音、-1dBを超えるピークがない。
- 素材一覧、使用時間、不足素材、QAレポートが更新される。

## 差し替え

- 新素材は別名で追加し、設定ファイルの参照先を変更する。
- 実プレイ動画はシーンの`background`へ指定可能。
- 横長動画は自動で画面を埋め、`focus_x` / `focus_y`で注視位置を調整する。
- 大きな変更前にプレビューで確認し、最終版を直接作り直さない。
